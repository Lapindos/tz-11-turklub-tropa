# Лист leads

Таблица называется `Tropa — Bookings`. Лист — `leads`. Одна строка — одна заявка.

## Столбцы

| Столбец | Тип | Обязательно |
|---|---|---|
| `request_id` | текст, `REQ-` и UUID | да |
| `created_at` | дата и время, ставит Apps Script | да |
| `name` | текст, 2–60 символов | да |
| `phone` | текст, `+7` и 10 цифр | да |
| `email` | текст | нет |
| `trip_id` | список: `icefalls`, `snowshoes`, `sunrise`, `plateau`, `traverse`, `newyear_hut` | да |
| `trip_date` | дата выезда | да |
| `participants` | число 1–6 | да |
| `utm_source` | текст, пусто на сайте становится `direct` | да |
| `utm_medium` | текст, пусто становится `none` | да |
| `utm_campaign` | текст, пусто становится `not_set` | да |
| `utm_content` | текст, пусто становится `not_set` | да |
| `status` | список | да |

## Статус

Проверка данных на столбец M, список:

```text
new,contacted,prepaid,went,lost
```

Другое значение отклонять. Что означает каждый статус:

| status | Этап |
|---|---|
| `new` | Новая бронь |
| `contacted` | Связались |
| `prepaid` | Предоплата внесена |
| `went` | Участвовал в походе |
| `lost` | Отказ |

Для проверки дашборда одну тестовую заявку проведите до `went`, другую закройте `lost`.

## Подсветка

Пустые обязательные ячейки, строка 2 и вниз. Почта в столбце E не обязательна.

```text
=AND($A2<>"";OR($A2="";$B2="";$C2="";$D2="";$F2="";$G2="";$H2="";$I2="";$J2="";$K2="";$L2="";$M2=""))
```

Повтор `request_id`:

```text
=AND($A2<>"";COUNTIF($A:$A;$A2)>1)
```

Доступ на просмотр откройте для почты заказчика, которую дал преподаватель. В коде приёмника паролей нет, идентификатор таблицы хранить можно.
